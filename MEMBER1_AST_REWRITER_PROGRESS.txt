2. TECHNICAL DETAILS & IMPLEMENTATION
--------------------------------------------------------------------------------
A. AST Assignment Detection (pychronicle/rewriter/analyzer.py)
   Python has many ways to assign or rebind variables beyond simple `x = 1`. 
   I created `ASTAnalyzer` (subclassing `ast.NodeVisitor`) to detect 14 different forms:
   - Simple assignments (`x = 1`)
   - Augmented assignments (`x += 1`, `x *= 2`)
   - Annotated assignments (`x: int = 10`)
   - Unpacking (`a, b = 1, 2` and starred targets `a, *rest = items`)
   - Walrus operator / named expressions (`if (n := len(items)):`)
   - Loop variable bindings (`for i in range(...)`)
   - Context manager bindings (`with open(...) as f:`)
   - Exception handlers (`except Exception as err:`)
   - Function parameter bindings (positional, default, *args, **kwargs)
   - Function and Class definitions
   - Subscript and Attribute mutations (`d['key'] = val`, `obj.attr = val`)
   - Import aliases (`import math as m`)

   I also built `ast_analyzer.py` as a command-line script so anyone can run:
   `python ast_analyzer.py path/to/script.py` and see the breakdown.

B. In-Memory AST Rewriting (pychronicle/rewriter/transformer.py)
   I implemented `ASTRewriter` (subclassing `ast.NodeTransformer`).
   - It injects `__pychronicle_hook__(line_no, scope, locals(), event_type)` 
     right after assignments and before returns/jumps.
   - It leaves the original source file untouched and compiles the modified AST 
     directly with Python's built-in `compile(tree, filename, 'exec')`.
   - It preserves original line numbers using `ast.copy_location` so stack traces 
     remain accurate, and ensures docstrings stay at the top of functions/classes.

C. Runtime Execution Tracer (pychronicle/tracer/engine.py)
   I implemented `ExecutionTracer` using `sys.settrace`:
   - Frame Filtering (`TraceFilter`): It ignores standard library files, 
     site-packages, and internal PyChronicle code so we only trace the target script.
   - Reentrancy Guard: When saving to SQLite, the tracer temporarily disables 
     its internal dispatch (`_in_hook = True`) so database operations don't trigger 
     recursive trace calls.
   - Clean State: Strips internal dunders (`__builtins__`, `__doc__`) so we only 
     store meaningful user variables.
   - Captures `'line'`, `'call'`, `'return'`, and `'exception'` events.

D. Unified Runner (pychronicle/runner.py)
   `PyChronicleRunner` ties together AST parsing, execution tracing, and Member 3's 
   StorageManager so that the TUI or CLI can run a script in a single call.
