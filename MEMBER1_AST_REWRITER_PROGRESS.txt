2. TECHNICAL DETAILS & IMPLEMENTATION
--------------------------------------------------------------------------------
A. AST Assignment Detection (pychronicle/rewriter/analyzer.py)
   Detects 14 distinct Python variable assignment forms:
   - Simple (`x = 1`), Augmented (`x += 1`), Annotated (`x: int = 10`)
   - Unpacking (`a, b = 1, 2`), Starred (`a, *rest = items`)
   - Walrus operator (`if (n := len(items)):`)
   - Loop variable bindings (`for i in range(...)`, `async for`)
   - Context manager bindings (`with open(...) as f:`, `async with`)
   - Exception handlers (`except Exception as err:`)
   - Function parameter bindings and function/class definitions
   - Subscript/Attribute mutations (`d['k'] = v`, `obj.attr = v`)
   - Import statements and aliases (`import math as m`)

B. Runtime Execution Tracer (pychronicle/tracer/engine.py)
   - Intelligent frame filtering: ignores standard library and site-packages.
   - Reentrancy locks: prevents recursive tracing when database queries run.
   - Dunder stripping: keeps variable state snapshots clean.
   - Lifecycle hooks: `'line'`, `'call'`, `'return'`, `'exception'`.

C. Delta Compression Engine (pychronicle/storage/delta.py)
   - Computes differences between frames: `added`, `modified`, `deleted`.
   - Deepcopy snapshotting: detects in-place mutations of lists, dicts, and sets.
   - Periodic keyframes: full-state checkpoints every K frames (default 50) 
     ensuring O(1) bounded timeline seeking.
   - Linear O(N) reconstruction: transparently restores full variable state trees.
   - Storage savings: 85% to 95% reduction on loop-intensive workloads.

D. Click CLI & Packaging (pychronicle/cli.py)
   - `pychronicle run <script>`: traces script and opens Textual TUI.
   - `pychronicle view <db>`: time-travel through pre-recorded sessions.
   - `pychronicle analyze <script>`: runs static AST assignment analysis.
   - `pychronicle watch <script> --var <name>`: displays mutation history table.
   - `pychronicle benchmark <script>`: compares raw Python, full-state, and delta modes.
   - Packaged with modern `pyproject.toml` and `setup.py`.

E. Crash Time-Travel Debugging (pychronicle/runner.py & pychronicle/ui/app.py)
   - Catches unhandled exceptions without crashing the debugger.
   - Launches TUI at the exact failure line with an Unhandled Exception Banner.
   - Allows stepping backward in time (`[h]`) to inspect variable states before the crash!
