2. TECHNICAL DETAILS & SUBSYSTEM ARCHITECTURE
--------------------------------------------------------------------------------
A. Normalized Database Schema (pychronicle/storage/database.py)
   - `executions`: session records with timestamps and environment metadata.
   - `trace_events`: monotonic sequence ordering, line numbers, function scope,
     event types (`line`, `call`, `return`, `exception`), and `is_delta` flags.
   - `variable_states`: variable names, JSON serialized payloads, and type hints.
   - Indexed for ultra-fast time scrubbing:
     `idx_events_exec_seq` on (execution_id, sequence)
     `idx_var_states_event` on (event_id)
     `idx_var_states_name` on (var_name)

B. Cycle-Safe Serializer (pychronicle/storage/serializer.py)
   - Safely sanitizes arbitrary Python objects without crashing on cycles (e.g. `a = [a]`).
   - Automatically truncates massive strings/collections to prevent memory bloat.
   - Graceful fallbacks for unpicklable types (open file handles, sockets, functions, lambdas).

C. Delta Compression & Keyframing (pychronicle/storage/delta.py)
   - Compares frame t-1 with frame t to record only `added`, `modified`, and `deleted` variables.
   - Checkpoint interval places keyframes every K steps and at scope entry.
   - Reconstructs full states seamlessly on `storage.get_events()`.

D. High-Level Facade (pychronicle/storage/manager.py)
   - Abstracted API: `start_execution()`, `record_event()`, `get_events()`,
     `get_state_at()`, `get_variable_history()`, `get_storage_stats()`.
   - Backward-compatible with Weeks 1 & 2 full-state recording while supporting 
     Week 3 high-efficiency Delta Mode.
