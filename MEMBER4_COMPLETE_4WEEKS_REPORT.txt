2. UI Architecture & Component Details
--------------------------------------------------------------------------------
The TUI is modularized into dedicated widgets under `pychronicle/ui/`:

1. `PyChronicleApp` (`pychronicle/ui/app.py`):
   - Central coordinator for the application.
   - Manages data loading from `StorageManager`, message routing between widgets,
     modal screen presentation, and keyboard bindings.
   - Includes a self-contained fallback demo trace (`demo_algorithm.py`) so the app
     runs out-of-the-box without requiring an external database file.

2. `CodeViewer` (`pychronicle/ui/code_viewer.py`):
   - Uses `rich.syntax.Syntax` to format source code with line numbers and Monokai styling.
   - Dynamically highlights the currently executing line (`active_line`).
   - Keeps the active line in view using `scroll_to(y=max(0, active_line - 5))` so the
     user never loses sight of execution in long files.
   - Handles missing source files safely by displaying an informational notice.

3. `TimelineControl` (`pychronicle/ui/timeline.py`):
   - Bottom scrubber widget showing step index, total steps, and a visual progress bar.
   - Includes step navigation buttons (`⏮ First`, `◀ Prev`, `▶ Play / ⏸ Pause`, `Next ▶`, `Last ⏭`).
   - Autoplay engine supports multiple speeds (`0.5x`, `1.0x`, `2.0x`, `4.0x`) and
     automatically stops when reaching the final execution step.
   - Emits `TimelineControl.StepChanged` when the user scrubs or navigates.

4. `VariableViewer` (`pychronicle/ui/variable_viewer.py`):
   - Textual `DataTable` displaying local variables.
   - Columns: Status (`Δ`), Variable, Type, Current Value, and Mutation Delta.
   - Calculates mutations on every step and sorts modified variables to the top.
   - Real-time search bar (`#var-filter`) updates the table on every keystroke.
   - Clicking a row selects the variable and adds it directly to the watch list.

5. `WatchViewer` (`pychronicle/ui/watch_viewer.py`):
   - Displays developer-selected variables across execution time.
   - Shows active value (or "(out of scope)") and mutation count.
   - Renders chronological mutation badges for past states.
   - Clicking any badge emits `JumpToStep`, instantly jumping the debugger to that step.
   - Supports adding watches via `AddWatchModal` or removing via the `✕` button.

6. `AddWatchModal` & `HelpModal` (`pychronicle/ui/modals.py`):
   - `AddWatchModal`: Clean popup with variable name input and auto-suggestions from
     current scope.
   - `HelpModal`: Keyboard shortcut guide with quick-close on `Esc` or `Enter`.

3. CLI Packaging & Commands
--------------------------------------------------------------------------------
The project is packaged with standard Python packaging (`pyproject.toml`) and
a dedicated CLI module (`pychronicle/cli.py`):

• `pychronicle run <script.py>`
  Executes a Python script under `sys.settrace`, records all line executions and
  local variable dictionaries into an in-memory SQLite storage session, and
  launches the interactive TUI.

• `pychronicle view <trace.db> [--exec-id ID] [--script file.py]`
  Loads a pre-recorded SQLite trace database produced by the storage engine
  and allows stepping through historical execution.

• `pychronicle demo`
  Launches the interactive 4-week demo session with pre-populated trace events
  and watch variables (`total_sum`, `fib_sequence`).

• `python -m pychronicle`
  Works directly without installation via standard Python module execution.

6. Keyboard Shortcuts Quick Reference
--------------------------------------------------------------------------------
  Right / l       -> Step forward 1 event
  Left / h        -> Step backward 1 event
  Home / g        -> Jump to start (Step 1)
  End / G         -> Jump to end (Last step)
  Space / p       -> Toggle play / pause (Autoplay)
  w               -> Add variable to Watch Panel (opens modal)
  f               -> Focus variable search filter
  ?               -> Open keyboard shortcuts help modal
  q / Ctrl+C      -> Exit PyChronicle
